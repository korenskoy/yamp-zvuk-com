# Code of Conduct

This project follows the **Contributor Covenant**, version 2.1.

The full text of the Code of Conduct is published by its authors at:

- English: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
- Russian: https://www.contributor-covenant.org/ru/version/2/1/code_of_conduct/

By participating in this project — opening issues, submitting pull requests, commenting, or otherwise engaging with the community — you agree to abide by its terms. In short: treat other contributors with respect, assume good faith, focus on what is best for the project and the community.

## Scope

This Code of Conduct applies within all project spaces — the GitHub repository (issues, pull requests, discussions, code reviews, commit messages), and any other communication channel officially associated with the project.

It also applies when an individual is representing the project in public spaces, for example using an official project email address, posting via an official social media account, or acting as an appointed representative at an online or offline event.

## Reporting

If you witness or experience behaviour that violates this Code of Conduct, please report it privately to the project maintainer:

- **Email:** korenskoy@gmail.com
- **GitHub:** open a private security advisory at https://github.com/korenskoy/yamp-zvuk-com/security/advisories/new (use it for CoC reports as well — it is the only private channel GitHub offers for this repository)

All reports will be reviewed and investigated promptly and fairly. The maintainer is obligated to respect the privacy and security of the reporter.

## Enforcement

The project maintainer is responsible for clarifying and enforcing this Code of Conduct, and will take appropriate and fair corrective action in response to any behaviour deemed inappropriate, threatening, offensive, or harmful.

Consequences for violations follow the **Enforcement Guidelines** of Contributor Covenant 2.1, published at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines

These range from a private warning, through a temporary ban from project spaces, up to a permanent ban, depending on the nature and severity of the violation.
