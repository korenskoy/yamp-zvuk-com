# Changelog

## v1.2.3

### Поиск
- Вкладки поиска (Артисты/Треки/Альбомы/Подкасты/Плейлисты) теперь используют персекционные API — каждая вкладка грузится лениво и поддерживает пагинацию
- Кнопка «Загрузить ещё» в конце списка — подгружает следующую страницу по курсору
- Обновление `zvuk-swift` до 0.3.0: исправлены фильтры разделов и курсоры, которые молча игнорировались сервером

## v1.2.2

### Улучшения
- Единая обработка ошибок через `AppError` — русскоязычные сообщения вместо сырых ошибок
- Кастомный `AccentButtonStyle` вместо `.borderedProminent` — кнопки больше не пропадают при потере фокуса окна
- Рефакторинг views: извлечены подвиды, inline-логика вынесена в методы
- Общая чистка кодовой базы: эффективность, переиспользование, последовательные API-запросы

### Исправления
- Исправлен CoverSheet: режим заполнения обложки, фиксированная ширина иконки play/pause

## v1.2.1

### Плеер в CoverSheet
- Кнопки управления воспроизведением прямо в окне обложки
- Кликабельные имена артистов - переход на страницу артиста по тапу

### Улучшения
- Обновленный лейаут: название и артисты слева, кнопки управления справа
- Плейсхолдер для треков без обложки

### Исправления
- Исправлена фильтрация и ID секций на странице «Популярное»
- Интеграция SwiftLint как build plugin

## v1.2.0

### Новое
- **Раздел «Популярное»** — новая страница в боковой панели с контентом из редакционных гридов Zvuk: новые релизы, жанровые плейлисты, актуальные хиты, подборки от редакции, треки недели и топ-100
- Горизонтальные карусели с кнопкой раскрытия в полноэкранную сетку
- Секции с треками в двухколоночной раскладке с нумерацией
- Устойчивость к ошибкам — сбой загрузки одной секции не ломает всю страницу

### Улучшения
- Спиннер загрузки теперь по центру экрана на всех страницах (Главная, Популярное, Чёрный список)
- Обновлена библиотека `ZvukMusic` до 0.2.0 (поддержка Grid API)

### Исправления
- Убран конфликт клавиши `Esc` при открытой обложке трека — больше не переключает трек

## v1.1.1

### Что нового

### Исправления
- Исправлена реактивность настроек — переключение скробблинга и качества звука теперь мгновенно отражается в UI
- Исправлена вёрстка PlayerBar — секции распределены равномерно

### Прочее
- Добавлены ссылки на GitHub репозиторий приложения и библиотеки ZvukMusic в настройках
